# Bundled fonts

All fonts in this directory are distributed under the SIL Open Font License,
Version 1.1 (https://scripts.sil.org/OFL), fetched from Google Fonts
(fonts.gstatic.com) via the public google-webfonts-helper API. The OFL permits
bundling, embedding into documents, and redistribution.

| Family        | Designer / foundry                          |
|---------------|----------------------------------------------|
| Roboto        | Google / Christian Robertson                  |
| Open Sans     | Google / Steve Matteson                       |
| Lato          | Łukasz Dziedzic                               |
| Source Serif 4| Adobe / Frank Grießhammer                     |
| Merriweather  | Sorkin Type / Eben Sorkin                     |
| PT Serif      | ParaType                                      |
| JetBrains Mono| JetBrains                                     |
| IBM Plex Mono | IBM                                            |

Each family is included as four static weights (Regular, Bold, Italic,
BoldItalic) to support the app's Bold/Italic toggles without on-the-fly
synthesis. No modifications were made to the font files themselves.
